# Лабораторная работа №22. Интерактивные веб-приложения на JavaScript

## 1. Описание проекта
Лабораторная рабо с целью закрепить и систематизировать знания по
JavaScript путём разработки интерактивных веб-приложений с использованием HTML,
CSS и JavaScript, а также закрепить навыки работы с системой контроля версий Git и
удалёнными репозиториями GitHub.

## 2. Функциональность
- **Операции**: сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`), ввод дробных чисел (через точку), очистка (`C`), вычисление (`=`).
- **Ограничения**: запрещены два оператора подряд, оператор в конце выражения, две точки в одном числе; деление на ноль вызывает ошибку.
- **Обработка ошибок**: при некорректном выражении на дисплее выводится «Ошибка». После ошибки любое нажатие (кроме `C`) начинает новый ввод. Кнопка `C` всегда сбрасывает состояние.

## 3. Архитектура
**Структура файлов**:
- calculator
  - index.html
  - style.css
  - main.js
  - calculator.js 

- **Класс Calculator**:
- Поля: `displayElement` , `expression` , `hasError` .
- Методы: `init()` – навешивает обработчики; `handleButtonClick()` – главный обработчик; `clear()` – сброс; `updateDisplay()` – обновление интерфейса; `showError()` – переход в состояние ошибки; `safeEvaluate()` – безопасное вычисление; `isValidExpression()` – валидация выражения; `isOperator()`, `isLastCharOperator()`, `hasDuplicateDot()` – вспомогательные проверки.
- **Взаимодействие**: события `click` привязаны к кнопкам через `forEach` → вызов `handleButtonClick` → изменение состояния → вызов `updateDisplay`.

## 4. Логика работы 

### Последовательность действий при нажатии кнопок
1. **Обработчик события** получает текстовое содержимое нажатой кнопки (`value`).
2. Если `hasError === true` и `value !== "C"` – сначала вызывается `clear()`.
3. Далее выполняется ветвление:
 - `value === "C"` → `clear()` (сброс `expression`, `hasError = false`, дисплей = `"0"`).
 - `value === "="` → `safeEvaluate(expression)`. Внутри проверяется `isValidExpression()`, затем вызывается `eval()`. Результат преобразуется в строку и сохраняется в `expression`, либо вызывается `showError()`.
 - Иначе  → запускаются валидационные проверки; при успехе символ добавляется в `expression`.

### Валидация ввода
- **Двойные операторы**: метод `isLastCharOperator()` проверяет последний символ `expression`. Если он оператор и новый символ тоже оператор – добавление блокируется.
- **Точка**: метод `hasDuplicateDot()` выделяет последнее число (всё после последнего оператора) и проверяет, содержит ли оно точку. Если да – вторая точка не допускается.
- **Оператор в конце**: перед вычислением `isValidExpression()` дополнительно проверяет, что последний символ не оператор.
- **Пустое выражение**: `safeEvaluate()` не запускается, если `expression` пусто.

### Вычисление
- Используется встроенная функция `eval()`, но она вызывается только после успешной валидации через `isValidExpression()`, которая проверяет:
- Отсутствие двух операторов подряд (регулярное выражение или перебор символов).
- Отсутствие оператора на последней позиции.
- `safeEvaluate` обёртывает вызов `eval` в `try...catch`, чтобы перехватывать синтаксические ошибки и деление на ноль. В случае исключения вызывается `showError()`.
- После успешного вычисления результат (число) преобразуется в строку и сохраняется в `expression`, что позволяет продолжать цепочку вычислений.
